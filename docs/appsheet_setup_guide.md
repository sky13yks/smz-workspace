# AppSheet アプリ構築手順（GWS基幹DB連携）

初期構築したスプレッドシート（基幹DB）を元に、Googleのノーコードツール「AppSheet」でアプリを作成する手順です。AppSheetを使えば、PC・スマホ・タブレットのどれからでも案件データを閲覧・編集・追加できる業務アプリが爆速で完成します。

---

## 1. アプリの自動生成

スプレッドシートの画面から、ワンクリックでAppSheetアプリを自動生成します。

1. 初期構築が完了したスプレッドシートを開きます。
2. 上部メニューから **「拡張機能」 ＞ 「AppSheet」 ＞ 「アプリを作成」** をクリックします。
3. 数十秒待つと、別タブでAppSheetのエディタ画面が立ち上がり、スプレッドシートのデータを元にした初期アプリが自動生成されます。
   - ※AppSheetの規約同意画面やログイン画面が出た場合は、ご自身のGoogleアカウントでログイン・同意して進めてください。

---

## 2. マスタデータ（別のシート）の読み込み

初期状態では、一番左にある「案件管理DB」シートしか読み込まれていません。「顧客マスタ」と「設定マスタ」もアプリ内に取り込みます。

1. AppSheetエディタの左側メニューから **「Data」** （円柱のアイコン）をクリックします。
2. 画面上部または中央に、スプレッドシート内の別シート（`顧客マスタ`、`設定マスタ`）を追加するかどうかのサジェスト（提案）が表示されるので、**「＋ Add」** をクリックして両方とも追加します。

---

## 3. カラム（列）の型設定

AppSheetでは、各項目の「型（Type）」を正しく設定することが使いやすさに直結します。
左側メニューの **「Data」** から **「案件管理DB」** テーブルを選び、**「View Columns」** または画面中央のリストから以下の項目を調整します。

### 【ステータス・対象業務のドロップダウン化】
ユーザーが手入力せず、ステータスや対象業務を選択できるようにします。
1. **ステータス** および **対象業務** の `Type` を **「Enum」**（単一選択）に変更します。
2. 変更後、その列の左側にある鉛筆マーク（Edit）をクリックし、`Valid If` （または `Data Validity`）の項目に以下を入力して保存します。
   - ステータスのValid If: `設定マスタ[ステータス区分]`
   - 対象業務のValid If: `設定マスタ[対象業務]`

### 【顧客の紐付け（Ref設定）】
案件に顧客マスタを紐付け、顧客を選択できるようにします。
1. **顧客名** の `Type` を **「Ref」** に変更します。
2. `Source table`（参照先テーブル）を **「顧客マスタ」** に設定して **「Done」** を押します。

### 【URLやリンクの設定】
添付ファイルやドライブへのリンクを押しやすくします。
1. **ドライブフォルダURL** など各種URL項目の `Type` を **「URL」** に変更します。

### 【自動入力（Initial value）の設定】
1. **登録日時** の `Initial value` に `NOW()` を設定します（自動で現在時刻が入ります）。
2. **案件ID** の `Initial value` に `UNIQUEID()` を設定すると、一意のランダムIDが自動で入ります（後ほど、「PRJ-2401-001」のような連番ルールにする場合は変更可能です）。

最後に画面右上の **「SAVE」**（保存）ボタンを押します。

---

## 4. ビュー（画面表示）の調整

使いやすい画面（一覧画面、カレンダーなど）を整えます。

1. 左側メニューの **「Views」**（スマホのようなアイコン）をクリックします。
2. 下部にある **「＋ New View」** をクリックし、新しい画面を作ります。
   - **ボードビュー（かんばん形式）**: `View type` を `board` にし、`Group by` を `ステータス` にします（Notionのボードビューのような見た目になります）。
   - **リストビュー**: `View type` を `table` または `deck` にして、必要な項目を表示させます。
3. 画面右上の **「SAVE」** を押して完了です。

---

### 次のステップ
上記の手順で基本的な「データ閲覧・入力・編集」ができるアプリが完成します。右側のプレビュー画面で操作を試してみてください。

この状態までできましたら、次は以下のいずれかの自動化・カスタマイズに進むのがおすすめです！
1. **AppSheet Automation** または **GAS** を使った「Googleドライブ自動フォルダ作成」機能の追加。
2. 案件IDを `PRJ-YYMM-001` といった分かりやすい連番で自動採番する設定。
3. レポート（PDF）の自動出力機能の構築。
