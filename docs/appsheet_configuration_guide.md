# AppSheet 高度UI/UX設定ガイド (15テーブル対応版)

ブラウザエージェントで確認したところ、**なんとすでに15個すべてのテーブルがAppSheetに完璧に読み込まれていました！**
これにより、いよいよアプリ側の魔法（UI分岐や金額自動計算）をかけるフェーズに入ります。

ここでは、「修理を選んだら写真フォームが出る」といったUXのキモとなる設定方法を部位別にまとめました。

---

## 1. カラム型（Type）とリファレンス（Ref）の設定

各テーブルどうしを繋げる（線を引く）作業です。
AppSheetエディタの `Data > Columns` から、以下の設定を行ってください。

### A. 起点となる「活動ログ」の設定
`1. 活動ログ (DealsLogs)` テーブル
*   **大分類**
    *   `Type`: Enum
    *   `Values`: `工具`, `中古機械`, `新品機械`, `修理`
    *   `Input mode`: Buttons
*   **アクション**
    *   `Type`: Enum
    *   `Values`: `見積書作成`, `発注書作成`, `売買契約書作成`, `修理報告作成`, `メンテログ記録`
    *   `Input mode`: Dropdown
*   **会社ID**
    *   `Type`: Ref
    *   `Source table`: `M1. 顧客_仕入先 (Companies)`
*   **担当者ID**
    *   `Type`: Ref
    *   `Source table`: `M3. スタッフ (Staff)`

### B. 機械メンテ（写真・メモ連動）の設定
`3. 機械メンテ詳細 (MaintDetails)` テーブル
*   **メンテID**
    *   `Type`: Ref
    *   `Source table`: `2. 機械メンテ (MachineMaint)`
    *   🌟 **重要**: `Is a part of?` に必ずチェックを入れてください！（これにより、2の画面の中に写真とメモの手軽な追加ボタンが現れます）
*   **現場写真_URL**
    *   `Type`: Image

### C. 工具メンテの設定
`4. 工具メンテ (ToolMaint)` テーブル
*   **工具製造番号**
    *   `Type`: Ref
    *   `Source table`: `M5. 工具マスタ (Tools)`
*   **コーティング膜種**
    *   `Type`: Enum
    *   `Values`: `TiN`, `TiAlN`, `TiCN`, `マーキュリー`, `なし`
    *   `Input mode`: Dropdown

## 2. 魔法の表示切り替え（Show_If）の設定

ユーザーがAppSheet上で「不要な項目を見なくて済む」ようにする設定です。
`Data > Columns` の各カラムの鉛筆マーク（編集）を押し、`Show? (Show_If)` のフラスコマークに式を入力します。

**(例1) 「大分類」で【修理】が選ばれた時だけ表示するカラム**
*   活動ログにて、修理に関する項目があればこの式を入れます。
*   **式:** `[大分類] = "修理"`

**(例2) 「工具メンテ」の【価格補正理由】の入力欄**
*   研磨量を入れて価格が変動した、あるいは値引きした理由などを入れる欄は、普段は隠しておき、補正した時だけ出します。
*   対象カラム: `4. 工具メンテ` の `価格補正理由`
*   **式:** `ISNOTBLANK([算出価格])` (※実際には金額が手入力で上書きされた時など、条件を拡張可能です)

---

## 3. 価格や名称の自動引き継ぎ（Initial value / Formula）

**(例1) 会社IDを選んだら、その会社名を表示させたい場合（仮想の列を作る）**
*   AppSheetは、Ref設定をすると自動で相手先の「Label」設定されたものを表示してくれます。
*   `M1. 顧客_仕入先 (Companies)` の設定で、`会社名` カラムの `Label?` のチェックマークをオンにしておけば、活動ログなどで会社IDを選ぶ際に「会社名」がリストに表示されるようになります！

**(例2) 工具メンテの【算出価格】の自動計算**
*   対象カラム: `4. 工具メンテ` の `算出価格`
*   `Auto Compute > App formula` に複雑な計算式を入れることで、研磨量(0.5mm刻み)やコーティング種別から金額を自動算出させます。
*   *(※具体的なAppSheet用の長文関数は、マスターシートの構成が完全に固まったあとで最適化してご提供します！)*

---

まずは、上記「1. カラム型（Type）とリファレンス（Ref）の設定」をAppSheetエディタ上でポチポチと設定してみてください。UIが劇的にアプリらしく変わります！
