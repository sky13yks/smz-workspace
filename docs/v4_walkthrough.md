# システム検証ガイド (v4.0 準拠)

本ガイドでは、構築したシステムが設計通りに動作するかを確認するためのテストシナリオを定義します。

---

## 🧪 1. テストシナリオ：工具受注生産 (最長ルート)

| ステップ | 操作内容 | 期待される挙動 |
|---|---|---|
| 1 | `Home` から `新規案件` を追加 | T1 に追加され、ステータスが「引合」になる。 |
| 2 | `M1 会社` で顧客「A社」を選択 | 住所や締日が自動引用される。 |
| 3 | `T5` に「仕入見積書.pdf」をUP | **[自動]** ステータスが「見積作成中」に変わる。 |
| 4 | `T2` で販売見積を作成 | 利益率が自動計算される。 |
| 5 | `T5` に「販売見積書.pdf」をUP | **[自動]** ステータスが「見積提出済」に変わる。 |
| 6 | `T5` に「注文書.pdf」をUP | **[自動]** ステータスが「受注・発注済」に変わる。 |
| 7 | `T2` で「発注書」を Action で作成 | 元の見積明細がコピーされ、元帳票IDに紐づく。 |
| 8 | `T5` に「工具図面.pdf」をUP | **[自動]** ステータスが「承認図回程中」に変わる。 |

---

## 🧪 2. テストシナリオ：修理・メンテナンス

| ステップ | 操作内容 | 期待される挙動 |
|---|---|---|
| 1 | `Home` から `修理を記録する` | `大分類=修理OH` が初期入力されたフォームが開く。 |
| 2 | `A1` から既存個体を選択 | その工具の過去の研磨履歴(T6)が見れる。 |
| 3 | `T6` に作業記録を追加 | 研磨回数が +1 され、A1 の累計回数に反映される。 |
| 4 | 回数が閾値を超えた場合 | **[自動]** 通知(Notification)が飛ぶ。 |

---

## ✅ 最終確認チェックリスト

### 構造・連携
- [ ] 13枚のシートがすべて作成され、ヘッダーが正しいか
- [ ] T1 案件の下に複数の T1D 案件明細を追加できるか
- [ ] T2 帳票の「元帳票ID」を選択して枝分かれを表現できるか

### 自動化
- [ ] PDFアップロード時にステータスが期待通りに遷移するか
- [ ] 案件作成時に Google Drive フォルダが自動生成されるか(GAS)
- [ ] 締め日アラートのスライスに正しい案件が表示されているか

### UI/UX
- [ ] ランチャー(L1)から各フォームに 1-Click で遷移できるか
- [ ] モバイル端末で写真(T6)や図面(T5)が正しく撮影・閲覧できるか
