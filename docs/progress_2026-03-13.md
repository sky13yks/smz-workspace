## 完了済み作業

### 1. GitHub リポジトリ・ブランチ設定
- `smz-workspace` リポジトリ作成・初期コミット完了
- ブランチ保護ルール設定（`main`, `develop` への直接push禁止）
- 現在の作業ブランチ: `feature/v5-db-redesign`

### 2. 業務フロー分析（docs/workflow_review_questions.md）
7つの業務カテゴリについてヒアリング・整理済み：

| カテゴリ | 特記事項 |
|---------|---------|
| オーダーメイド工具 | 複数形状×複数メーカーの比較見積あり |
| カタログ品工具 | 電話注文→納品書のみ、というシンプルフローあり |
| 工具メンテナンス | 仕入見積不要・価格表（外径×厚みマトリクス）で算出 |
| 加工受託 | ブローカー形式、工具製作が同時発生することあり |
| 機械修理 | 見積なしで作業→完了後まとめて帳票、が多い |
| 中古機械 | 共同購入あり、2種類の販売価格（dealer/user）管理 |
| 新品機械 | MATRIX台湾との30%/70%前払い制、重量屋コスト発生 |

### 3. DB設計 v5.0（docs/v5_design_revised.md）
設計書を新規作成。v4から大幅改訂。

### 4. スプレッドシートDB再構築（gas/v4_db_setup.gs）
`setupV4Database` 関数をGASエディタで実行し、17シートを構築済み。

| グループ | シート |
|---------|-------|
| マスタ系 | M1_Companies, M2_Contacts, M3_ToolPricing, M4_Settings, M6_Tools |
| 資産系 | A1_Assets, A2_WorkSpecs |
| トランザクション系 | T1_Deals, T1D_DealItems, T2_Papers, T2D_PaperLines, T4_QuoteRequests, T4D_QuoteResponses, T5_Files, T6_WorkLogs, T7_RepairExpenses |
| システム系 | L1_Launcher |

**v4から変わった主な点：**
- `M1_Companies` に `掛け率` 列追加（工具メンテ販売価格 = 仕入価格 × 掛け率）
- `M3_ToolPricing` を外径×厚みのサイズ区分 × 作業種別マトリクスに再設計
- `M6_Tools` 新設（よく扱うオーダーメイド工具の雛形）
- `T1_Deals` に業務カテゴリ・修理区分・失注フラグ・事務担当者ID等を追加
- `T4_QuoteRequests` を形状バリアント単位に再設計
- `T4D_QuoteResponses` 新設（複数メーカーの回答比較）
- `T7_RepairExpenses` 新設（修理・出張費用明細）
