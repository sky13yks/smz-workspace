# AppSheet 魔法の数式集（価格計算・動的UI）

15テーブルを読み込んだAppSheetにおいて、アプリを「手打ち入力」から「全自動・直感的操作」へと進化させるための具体的な数式（Formula）集です。
AppSheetエディタの `Data > Columns` から、該当するカラムのフラスコマーク（Formula）にコピー＆ペーストしてください。

---

## 1. 工具メンテ (ToolMaint) の自動価格計算

ユーザーが「工具サイズ」と「研磨量」を入力した瞬間に、裏側のマスター（M7. 工具価格マスタ）から数値を引用し、0.5mm刻みで価格を自動算出する式です。

### A. 研磨価格の自動算出
対象カラム: `4. 工具メンテ` の仮想カラム（Virtual Columnを追加して `算出_研磨価格` と命名）

**App formula:**
```appsheet
ANY(SELECT(M7. 工具価格マスタ[基本価格], 
  AND(
    [区分] = "研磨",
    [外径_mm] = [工具製造番号].[外径],
    [厚み_mm] = [工具製造番号].[厚み]
  )
)) 
+ 
(
  CEILING(MAX(LIST(0, [研磨量] - 0.5)) / 0.5) 
  * 
  ANY(SELECT(M7. 工具価格マスタ[加算単価], 
    AND(
      [区分] = "研磨",
      [外径_mm] = [工具製造番号].[外径],
      [厚み_mm] = [工具製造番号].[厚み]
    )
  ))
)
```
*解説: 前半で基本価格（0.5mm迄）を引き当て、後半で「0.5mmを超える分を0.5単位で切り上げ（CEILING）」した回数分だけ加算単価を掛けています。*

### B. コーティング価格の自動算出
対象カラム: `4. 工具メンテ` の仮想カラム（Virtual Columnを追加して `算出_コーティング価格` と命名）

**App formula:**
```appsheet
IF([コーティング膜種] = "なし", 
  0, 
  ANY(SELECT(M7. 工具価格マスタ[基本価格], 
    AND(
      [区分] = "コーティング",
      [外径_mm] = [工具製造番号].[外径],
      [厚み_mm] = [工具製造番号].[厚み],
      [コーティング種別] = IFS(
        [コーティング膜種]="TiCN", "TiN", 
        TRUE, [コーティング膜種]
      )
    )
  ))
)
```
*解説: TiCNが選ばれた場合は、マスター上で「TiN」の価格を探しにいくように `IFS` で置換（マッピング）しています。*

## 2. 動的UI（Show_If）の数式

「必要な時だけ見せる」を実現するための式です。該当カラムの `Show?` プロパティのフラスコマークに入力します。

### A. 修理の時だけ出す（活動ログ）
対象カラム: 活動ログ内で「修理」でしか使わない項目
**Show_If:**
```appsheet
[大分類] = "修理"
```

### B. 工具の時だけ出す（活動ログ）
対象カラム: 活動ログ内で「工具」でしか使わない項目
**Show_If:**
```appsheet
[大分類] = "工具"
```

### C. 研磨量が0の時は価格補正理由を隠す（工具メンテ）
対象カラム: `4. 工具メンテ` の `価格補正理由`
**Show_If:**
```appsheet
[研磨量] > 0
```

## 3. IDの自動採番（Initial value）

案件やメンテログを作成した瞬間、自動でID（文字列）を割り当てる設定です。`Initial value` に設定します。

### 活動ログの「ログID」
対象カラム: `1. 活動ログ` の `ログID`
**Initial value:**
```appsheet
"L-" & TEXT(TODAY(), "YYMMDD") & "-" & UNIQUEID()
```
*結果例: `L-240225-a1b2c3d4`*

これらの式をAppSheet上で設定することで、スプレッドシートやGASで処理するよりも「ユーザーがアプリ上で数値を打ち込んだ瞬間に、目の前で計算結果が出る」という最高のユーザー体験（UX）を作ることができます！
