## 帳票の種類と用途

| 帳票種別 | 種別コード | 送付先 | 目的 |
|---------|-----------|-------|------|
| 販売見積書 | 見積書 | 顧客 | 金額・仕様の提示 |
| 発注書 | 発注書 | 仕入先 | 仕入れの正式発注 |
| 納品書 | 納品書 | 顧客 | 商品・作業の引渡し確認 |
| 請求書 | 請求書 | 顧客 | 代金の請求 |

## Googleスプレッドシートテンプレートの作成手順

### ステップ1: テンプレートSSを作成

1. Googleドライブで「新規 → Googleスプレッドシート」
2. ファイル名: `【テンプレート】納品書_v4`（請求書も同様）
3. 以下のセルに固定情報を入力：

| セル | 内容 |
|------|------|
| A1 | 株式会社清水商會 |
| A2 | 〒（住所） |
| A3 | TEL / FAX |
| H1 | 納品書 ← ここを帳票ごとに変更 |

### ステップ2: プレースホルダ（書き込み先セル）の確認

GAS `generatePaperPdf()` が書き込むセルアドレス（v4_gas_papers.gs 119-127行目）：

| セル | 内容 | 現状 |
|------|------|------|
| B4 | 宛先会社名 | ダミー値 |
| H4 | 発行日 | `new Date()` |
| I9 | 帳票ID | paperId変数 |
| B15〜 | 明細品名 | details配列 |
| F15〜 | 数量 | details配列 |
| H15〜 | 単価 | details配列 |

> ⚠️ **実装TODO**: generatePaperPdf() の「ダミーデータ流し込み」部分（v4_gas_papers.gs 112-115行目）を
> 実際のT2_Papers / T2D_PaperLines / M1_Companiesからデータを引く処理に置き換える必要があります。

### ステップ3: 帳票IDを v4_gas_papers.gs に設定

```javascript
// v4_gas_papers.gs の先頭
const PAPER_TEMPLATE_ID = "ここに帳票テンプレートのスプレッドシートIDを指定してください";
const TEMP_PDF_FOLDER_ID = "ここにPDF作成用のテンポラリフォルダIDを指定してください";
```

スプレッドシートIDはURLの `/d/` と `/edit` の間の文字列：
```
https://docs.google.com/spreadsheets/d/【ここがID】/edit
```

## 納品書 固有項目

| 項目 | 内容 |
|------|------|
| 案件番号 | Y-YYMMDD-01 |
| 明細 | 納品物の品名・数量・単価 |
| 備考 | 保証条件、注意事項など |

## 請求書 固有項目

| 項目 | 内容 |
|------|------|
| 請求番号 | Y-YYMMDD-INV01 |
| 振込先 | 銀行名・支店名・口座番号 |
| 支払期限 | 締日ルールに従う（M1_Companies.締日） |
| 明細 | 請求内容・金額 |

---

## 実装優先順位

1. **最初に**: Googleスプレッドシートで納品書テンプレートを手動作成
2. **次に**: PAPER_TEMPLATE_ID を実際のIDに更新
3. **次に**: generatePaperPdf() のダミーデータ部分を実データ取得に書き換え
4. **最後に**: AppSheet Automation → GENERATE_PDF アクションでテスト
