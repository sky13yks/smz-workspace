## ✅ 確認済み（工具業務）

- カタログ品は販売価格が公開されており、電話注文→納品書のみ、というフローが存在する
- オーダーメイド工具は1案件で複数メーカーへRFQ、複数形状で比較見積もりあり
- 販売後、工具個体を登録してメンテナンス管理（研磨/コーティング/再コーティング）
- メンテナンスは見積・注文書なしで引取→納品、というシンプルな流れも存在する

## ❓ 確認が必要な事項

### 【A】工具業務の補足

**A-1. カタログ品の価格決定**
メーカーから「この価格で売れ」と指定されることがあるとのことですが、
その価格は毎回変わりますか？それとも比較的安定していますか？
→ M6_Tools（工具マスタ）に「標準売価」列を持つべきかどうかの判断に使います。

```
回答：指定される場合は10%のことが多いです。
（例：10万円だったら1万円）

比較的安定していると言えます。
```

**A-2. メンテナンスの発生元**
メンテナンスを依頼してくる工具は、
- (a) 自社が以前販売した工具（A1に登録済み）のみ
- (b) 他社から購入した工具でも受け付ける
どちらですか？

```
回答：他社から購入した工具も受け付けますが、99%は自社が以前販売した工具です。ただし、まだ工具のデータベースを正式には作成できていないため、今後はすべてのメンテナンスも工具の登録から実装する必要があります。
```

**A-3. 複数形状の見積もり**
「ベル型とディスク型で見積もる」場合、
- (a) 同じ案件の中で「形状A版の見積」「形状B版の見積」として管理したい
- (b) 案件を分けて管理する
どちらが業務的に自然ですか？

```
回答：(a) 同じ案件として、形状違いで見積もりをしていたという風に履歴を残したいです。また、メーカー違いで見積もりしたことも履歴に残したいです。
```

**A-4. メーカーの選定**
複数メーカーに見積依頼して回答が揃ったあと、どのように選定しますか？
- 価格だけで決める？
- 納期・品質・付き合いの長さなどで決める？
→ 「どのメーカーを選んだか」「なぜそのメーカーにしたか」をシステムに記録したいか確認します。

```
回答：メーカーによって強みがあります。
小モジュール・ミクロンホブと呼ばれる工具の世界では、伊沢技術研究所や小笠原プレシジョンラボラトリーなどが有名であり、小さい世界では優位性があります。選ばれるシチュエーションとしては、価格もありますが、形状や信頼性、納期など様々な理由でお客様が判断します。図面によっては海外への展開が不可だったりもします。そういった裏の事情を一言残せるようにしたいとも考えますが、必須項目ではないです。
```

### 【B】加工受託業務

**B-1. 加工の主体**
御社が加工受託を受けた場合、実際に加工するのは誰ですか？
- (a) 外部の加工業者へ再委託する（御社はブローカー）
- (b) 御社自身で加工する（自社工場・加工設備あり）
- (c) ケースによって異なる

```
回答：(a) 現状、加工設備は保有していません。ブローカーというのが正しいです。
```

**B-2. 典型的な依頼内容**
「加工受託」として来る依頼の代表例を教えてください。
（例：「歯切り加工を頼みたい」「キー溝加工を頼みたい」など）

```
回答：例の通り、歯切り加工やキー溝加工の他には、以下のような依頼が様々あります。
1. 全加工の依頼
2. 切断や曲げなど、特定の箇所のみの加工
3. ブランクの調達からの全加工
4. 工具製作が発生する依頼
   (a) 工具不要のケースもありますが、歯切り加工などの場合、一般的な歯型ではない可能性が高いため、専用工具を製作することもあります。
   (b) この場合、工具の見積もりと加工の依頼を1セットとして、同じ案件に紐付けたいです。(c) 加工と工具はワーク図面に紐づくため、同じ案件としてではなくても、そのワーク図面経由で紐づいたり、工具製作した足跡が残ればいいかなと思います。
これらの依頼内容に応じて、協力提携先に振り分けます
```

**B-3. 加工受託の流れ（想定）**
以下の流れで合っていますか？修正・補足をお願いします。

```
お客様から加工依頼
  ↓
ワーク図面・諸元を受け取る
  ↓
加工業者（仕入先）に見積依頼（図面送付）
  ↓
加工業者から見積回答
  ↓
お客様へ販売見積提出
  ↓
注文確定
  ↓
ワーク（材料）をお客様から受け取る？ or 加工業者へ直送？
  ↓
加工業者へ発注・ワーク送付
  ↓
加工完了品を受け取る
  ↓
お客様へ納品・請求
```

```
修正・補足：1. 工具製作が発生する場合、工具をメーカーに見積もるという手順が増えます。
2. ワークは基本的にお客様と加工先との直送で対応していただきます。
   (a) 弊社には営業の人間しかいないため、検品などの作業ができないためです。
```

**B-4. ワーク（材料）の流れ**
加工受託の場合、ワーク（加工対象物）はどのように動きますか？
- (a) お客様 → 御社 → 加工業者 → 御社 → お客様（御社が中継）
- (b) お客様 → 加工業者 → お客様（御社は書類のみ仲介）
- (c) ケースによる

```
回答：(b) が基本ですが、サイズや状況によっては弊社が一度引き取る可能性あり
```

### 【C】修理業務

**C-1. 修理の対象**
修理の対象は何ですか？
- (a) 工作機械（旋盤・マシニングセンタ等）
- (b) 工具（ホブ、カッター等）
- (c) 両方

```
回答：(a) 不具合調査のみや、オーバーホールやレトロフィット、修理部品調達もあります。
```

**C-2. 修理の主体**
修理を実際に行うのは誰ですか？
- (a) 御社のスタッフが現地へ行って修理
- (b) メーカーや修理業者を手配して立ち会い
- (c) 修理業者への橋渡しのみ（御社は行かない）

```
回答：現状では、以下の4パターンがあります。
1. 弊社の人間のみで行く場合
2. 弊社の人間と修理業者が行く場合
3. 修理業者のみが行く場合
4. メーカーサービススタッフのみが行く場合
メーカーサービスの人間が行く場合は、弊社の取り分は10%程度に設定されていることが多いです。
```

**C-3. 修理の典型フロー（想定）**
```
お客様から修理依頼
  ↓
現地へ行って状況確認（または電話・メールで状況ヒアリング）
  ↓
修理業者/メーカーへ見積依頼
  ↓
お客様へ修理見積提出
  ↓
注文確定
  ↓
修理実施（立ち会い or 工具引取）
  ↓
納品・請求
```

```
修正・補足：修理見積は提出されないことが多いです。修理対応をして完了した後に、作業報告書、見積書、納品書をまとめて発行することが多いです。その場合、注文書は発行されません。
メーカーサービスの修理の場合は、以下の一般的な手順を踏みます：
1. 事前に見積書を受け取り、お客様に見積書を提出
2. 注文をいただいた場合、メーカーへ発注をかける
3. メーカーから作業報告書と修正後の金額の連絡が来ます。
   これは、見積もり時は基本料金と延長料金を想定して、だいたい8時間で見積もりが来るため、実際の修理内容や対応時間が変更され、金額が変わることが多いためです。多くの場合、金額は安くなります。
```

**C-4. 同行修理費用**
「同行修理日額」の設定がありますが、これは：
- (a) 御社スタッフが出張する費用（交通費+日当）
- (b) 修理業者に支払う費用
- (c) 御社が請求する技術立会い費用

```
回答：弊社スタッフの同行修理については、1日あたりの日当を6万5000円としています。現在は基本料金のようなものを設定するか、金額についてはまだ確定していないところもあります。
また、休日対応することもあり、休日料金は日当8万円で想定していますが、以下の点については検討中です：
1. 基本料金と時間料金のように項目を分けるか
2. 請求の割合をどうするか
修理業者に支払う金額については、その都度納品書で確定します。
その他、以下の費用が発生します：
1. 高速代
2. ガソリン代
3. 昼食代
4. 部品代
なお、技術立ち合い費用については、現状ではいただいておりません。
```

### 【D】中古機械販売

**D-1. 仕入れ方法**
中古機械はどのように仕入れますか？
- (a) お客様から下取り
- (b) 中古機械業者から購入
- (c) 廃業・設備売却情報を入手して買取
- (d) 複数パターンあり

```
回答：(d) A、B、Cのすべてのパターンがあります。

1. 多くはお客様から下取りすることが多いです。
2. お客様から引き取り依頼があるパターン。
3. 同業者から「一緒にノリで買わないか」という誘いを受け、半分ずつお金を出し合って購入するパターン。売却したときの利益も半分ずつ分け合うという仕組みにて、買い付け・売り付けをすることもあります。中古機械の販売には、以下の3つのパターンがあります。
1. 弊社が共同で借りている倉庫へ持ち込み、メンテナンスをしてから販売するパターン
2. 現場でそのまま販売するパターン
3. 中古工作機械を取り扱っている業者から購入する（ブローカー形式の）パターン
弊社倉庫に持ってきた場合は、清掃コスト、塗装コスト、消耗部品や故障箇所の交換部品代などのコストが考えられます。また、倉庫を借りているため、その賃料もコストに含まれます。
さらに、中古機械の場合は、倉庫に搬入する際の運賃（重量屋さんに支払うコスト）も発生します。などが発生することがあります。
```

**D-2. 販売までの流れ**
仕入れてから販売するまでに何かしますか？
- (a) 整備・点検してから販売
- (b) そのまま販売（現状渡し）
- (c) ケースによる

```
回答：(c) 上述した通り、中古機械は「売り手側からのアプローチがある場合」と「買い手側からのアプローチがある場合」でシチュエーションが変わります。

1. 売り手側から引き取り依頼がある場合：
   (a) 工具を下見しに行く
   (b) 相場と比較し、査定を行う
   (c) 売買契約書を交わして購入する
   (d) 多くの場合は倉庫に持ってくる
   (e) 海外に売り手を探しておいて、そのまま海外へ発送するということもあります。
2. 買い手から中古機械を探してほしいという依頼があった場合
   (a) 中古機械百貨店、ネット、同業者などから情報を収集する
   (b) 見積もり依頼を行い、見積金額をお客様に提示する。ブローカーとして販売することもある
```

**D-3. 機械のスペック管理**
中古機械を登録するとき、どんな情報を記録しておきたいですか？
（例：メーカー、型式、年式、最大加工径、ストローク、重量、付属品、整備状況など）

```
回答：中古機械百貨店に大体のフォーマットがあるので、今はそれに準じて登録しています。また、ホームページの刷新も検討しており、順次情報を掲載したいと考えています。
カタログなどがPDFで存在する場合は、それらや動画などを紐付けて、運転状況や各主軸の情報を動画で公開したいという気持ちもありますが、基本的には現状、中古機械百貨店のフォーマットで記載しています。引き合いがあった際に誰でも回答できるように、機械の価格情報を社内で共有したいと考えています。
具体的には、以下の2点を共有する仕組みを構築したいです：
1. 商社から引き合いがあった際の商社価格
2. ユーザーから直接引き合いがあった際の販売価格
```

**D-4. 価格設定**
中古機械の売値はどのように決めますか？
- (a) 仕入値 × 掛率
- (b) 市場相場を調べて設定
- (c) 交渉制（定価なし）

```
回答：(b) 市場相場を調べて設定します。
この辺りはノウハウになってきてしまっており明文化はできていませんが、その機械が世の中に出ている台数が少なければ希少価値は高いですし、世に出ている機械であればなるべく早く売りたいので、価格を低めに設定する傾向にあります。
```

### 【E】新品機械販売

**E-1. 取扱メーカー**
新品機械はどのメーカーのものを扱いますか？
特定のメーカーの代理店・特約店ですか？

```
回答：台湾の歯車研削盤メーカーであるマトリックス・プレシジョン（Matrix Precision: https://www.matrix-machine.tw/jp/about.html）の日本代理店と強いコネクションがあるため、その販売店として機械を販売しています。
その他に取り扱いできないメーカーはないため、基本的には全てのメーカーの機械を等しく扱いますが、MATRIXに関しては今後特に強くプッシュしていこうと考えています。

今後の営業方針については以下の通りです：
1. 営業活動の強化
   (a) 年間3台の販売目標を達成するため、歯車研削加工を行っているお客様のリストを作成する
   (b) 定期的なヒアリングや推奨（リコメンド）といった積極的な営業を行う
   (c) 新規開拓にも注力する
2. 情報共有の仕組みづくり
   (a) MATRIX製の機械はある程度型式が定まっているため、機種ごとに対象顧客をリストアップする
   (b) 購入可能性などの情報をメンバー全員で共有できるようにする
```

**E-2. 流れ**
工具（オーダーメイド）と基本的に同じフローですか？
（お客様から引合い → メーカーへ見積依頼 → 販売見積提出 → 受注 → 発注 → 納品 → 請求）

```
回答：基本的な流れは工具（オーダーメイド）と近しいですが、新品機械の販売においては以下の点が異なります。

1. 重量屋のコスト発生
   中古機械と同様に、重量屋（運送・据付業者）のコストが発生する場合があります。
   (a) 重量屋に機械の重量、仕様、付属品、運搬距離を伝えて見積もりを依頼します。
   (b) その運送賃を、機械販売の見積書に「運搬費」などの項目として追加し、メーカーからの機械代金と合算して提示することがあります。

2. MATRIX 台湾との取引（前払い制度）
   MATRIX 台湾との取引は前払い制となっており、支払いタイミングが分かれます。
   (a) 発注時に総額の30%を前受金として支払い。
   (b) 台湾の工場出荷時に残りの7割を支払い。
   このため、納品書や請求書の作成が前受金扱いを含む変則的なフローになります。なお、日本メーカーの新品工作機械の場合は、基本的に工具と同じ流れになります。

3. 資料と見積書のボリューム
   工作機械は仕様書やカタログなどの資料が膨大になります。また、オプションなどの記載事項が増えるため、現状では見積書が数ページにまたがることがあります。
   (a) 今後の運用としては、仕様書を別紙で作成することを検討しています。
   (b) 見積書のフォーマット自体は基本的に1枚に収め、注釈等に「詳細は仕様書に準ずる」と記載して分ける形が望ましいと考えています。
```

**E-3. 据付・試運転**
納品時に据付・試運転の立会いはありますか？
その費用はシステムで管理したいですか？

```
回答：据付試運転は基本的に必ず立ち会いますが、その費用は機械代に乗せていることが多いため、据付試運転としての特別費用は徴収していません。

ただし、見積作成時の考え方として、お客様までの距離などで高速代やガソリン代、移動拘束時間が大体算出できるので、立ち合いにかかる費用を算出するのは良いかもしれません。現状では実装していません。
```

## 現行設計で見直しが必要な箇所（Claude分析）

### 1. ステータス遷移の柔軟化
現状の11ステップ強制フローは、カタログ品やメンテナンスに対応できない。
**→ 「業務カテゴリ」ごとに推奨フローを変え、ステップのスキップを許可する設計に変更が必要。**

### 2. 見積依頼（T4_QuoteRequests）の拡充
現行のT4では「複数形状×複数メーカー」の比較が難しい。

**→ M6_Toolsは「よく扱うオーダーメイド工具の雛形」として限定的に使う方が現実的。**

**→ T2の「相手先会社ID」+「種別」で分離するか、方針を決める必要あり。**
