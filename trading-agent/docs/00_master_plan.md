# マスタープラン — AI株式運用エージェント「SMZ Trader」

作成: 2026-07-11 / 運用者: 山口 朔矢 / 期間: 終身(目標チェックポイント15年)

---

## 0. 大前提(毎年読み直すこと)

- **自己資金・余剰資金のみ**。生活費・事業資金は絶対に入れない。
- **借金は決してしない**: 信用取引・レバレッジ・オプション・レバレッジ型ETFは全面禁止(現物のみ)。
- **資金0円は許容するが、設計上は防ぐ**: 資産が5万円(初期資金の25%)を割ったら全停止し、人間の明示的な再開操作なしには何もしない。
- **引き出しはいつでも自由**: 出金はシステムの一級機能。出金がペナルティになる設計にしない。
- 元本保証はない。以下の全ての数字は**シナリオであって予測ではない**。
- 法令遵守: 自己資金の自動売買に免許は不要。高速取引行為者登録は個人のインターネット経由Botには該当しない(コロケーション等の低遅延設備が要件)。税務は毎年適正に申告する。

## 1. ゴールの数学(ここから目を逸らさない)

**目標: ¥200,000 → ¥10,000,000 / 15年**

### 1-1. 追加入金なしの場合

必要年率は **+29.80%を15年間連続**。参考: 世界最高水準の投資家の長期実績が年率20%台前半。
つまり「20万円だけを回して15年で1000万円」は**宝くじに近いプロファイル**であり、
それを狙う設定は破産確率(資金0円)も大きく引き上げる。

| 年率 | 15年後(20万円一括) |
|---:|---:|
| 3% | 31万円 |
| 5% | 42万円 |
| 7%(市場平均) | 55万円 |
| 10% | 84万円 |
| 15%(超一流) | 163万円 |
| 20%(歴史的トップ) | 308万円 |
| **29.8%(必要値)** | **1,000万円** |

### 1-2. 「入金力」レバーを使う場合(推奨)

毎月の積立を加えると、必要リターンは現実的な水準まで下がる:

| 月積立 | 年率5% | 年率8% | 年率10% | 年率12% | 年率15% |
|---:|---:|---:|---:|---:|---:|
| 0円 | 42万 | 66万 | 89万 | 120万 | 187万 |
| 1万円 | 310万 | 412万 | 504万 | 619万 | 856万 |
| **2万円** | 577万 | 758万 | **918万** | **1,119万** | 1,524万 |
| 3万円 | 844万 | 1,104万 | 1,332万 | 1,619万 | 2,193万 |

**15年で1,000万円に必要な月積立額**: 年率10%なら約2.2万円/月、年率12%なら約1.8万円/月、年率15%なら約1.2万円/月。

### 1-3. 結論(3つのレバー)

到達確率は「①戦略の複利 × ②入金力 × ③時間」の掛け算で上げる。

- **Plan A(入金なし)**: 必要29.8%。本システムのアグレッシブ設定でも期待値はこれを下回る。達成は「強い上昇相場に当たる運」への依存が大きい。資金0円リスクを承知の上でのみ。
- **Plan B(推奨)**: 月2万円前後の積立 + 規律あるシステム運用(現実的な期待レンジ: 年率5〜15%)。このレンジなら15年で600万〜1,500万円。**目標達成の主経路**。
- **Plan C(時間レバー)**: 期間は「死ぬまで」なので、15年時点で未達でも複利は続く。15年はチェックポイントであり締切ではない。

> 積立するかどうか・金額は毎月のレポートを見て自由に決めればよい(システムは追加入金を前提にしない)。

## 2. 基本方針 — なぜ「AIに全部任せる」をしないのか

LLMに株価予測をさせて裁量売買させる設計は採らない。理由:
1. LLMの市場予測に持続的な優位性がある証拠はなく、検証も再現もできない。
2. 15年運用の敵は「一回の大当たり逃し」ではなく「一回の大損と規律崩壊」。

代わりに **「ルールベースのシステマティック戦略が主、AIは執行・監査・監視の補佐」** とする:

| 役割 | 担当 | 具体 |
|---|---|---|
| 売買判断 | ルール(コード) | トレンドフィルタ+モメンタム(§4)。検証可能・決定論 |
| リスク管理 | ルール(コード) | ガードレール+サーキットブレーカー(docs/02) |
| 注文の最終点検 | AI(Claude) | 構造的リスクの veto/縮小のみ。**追加・増額は構造的に不可能** |
| 日次レポート・異常検知 | システム+AI | 毎日のMarkdownレポート、AI所感メモ |
| 運用・改善の相棒 | AI(Claude Code) | 月次レビュー、バックテスト、コード改善 |

採用戦略(トレンドフォロー/クロスセクショナル・モメンタム)は学術・実務で最も長く検証されてきた
アノマリーの一つであり、「暴落相場で現金に逃げてドローダウンを浅くする」性質が
小資金の生存性と相性が良い。**ただし将来の有効性は保証されない**(→ §8 の kill 基準)。

## 3. 15年ロードマップ(フェーズとゲート)

各フェーズは**合格基準を満たすまで次に進まない**。焦りは敵。

### Phase 0: 構築(完了 — 本PR)
システム実装・テスト・ドキュメント。合成データでのE2E検証済み。

### Phase 1: ペーパートレード(3ヶ月以上)
- 実データ(Stooq/Alpaca)で `run-daily` を毎営業日実行(自動化は docs/04)。
- **資金投入は一切しない。** 口座開設の準備だけ並行(docs/03)。
- **合格基準(全て満たすこと)**:
  1. 60営業日以上、無人で日次サイクルが完走(データ欠損時のフェイルセーフ動作を含む)
  2. ガードレール/ブレーカーの誤発動・不発動ゼロ(月次レビューで確認)
  3. 月次リバランスの執行内容が事前のバックテスト・ロジックと一致
  4. 台帳検証(verify-ledger)が常にOK
  5. 運用者が全コマンドと停止手順を暗記している
- 不合格なら: 原因修正 → 期間リセットしてやり直し。

### Phase 2: 実弾¥200,000(1年)
- ブローカー: 米国株(docs/03 の選定手順で決定)。第一候補は**国内業者の公式API
  (Webull証券/moomoo証券 — 特定口座なら税務が最軽量)**、次点でIBKR(端数株+API最強だが
  一般口座のみ=確定申告+損失繰越不可)。AlpacaのLive口座は日本居住者可否が未確認(前提にしない)。
- 実装: `broker.py` に実ブローカーアダプタを追加し、**まず最小ロット(1万円分)で発注テスト**。
- 設定はデフォルト(コア70/サテライト30)のまま開始。アクセル(コア50/サテ50等)は1年後の年次レビューまで触らない。
- **ゲート(継続条件)**: ブレーカー発動時に手順書通り対応できたか / 税務記録が揃っているか。
- **撤退条件**: システム起因の誤発注・想定外損失が発生したら即ペーパーに戻す。

### Phase 3: 拡張(資産や経験に応じて)
- 総資産が**200万円超**になったら日本株ユニバース追加を検討(単元株制約が薄れるため。kabuステーションAPI + J-Quants)。
- 積立の自動化、Looker Studio等での可視化、戦略パラメータの年次見直し。

### Phase 4: 巡航(〜終身)
- 月次15分 + 年次1時間のレビュー(§8)だけで回る状態を維持。
- 資産が目標に近づいたら「守り」への段階移行(コア比率引き上げ)を年次レビューで判断。
- 万一の相続に備え、docs/04 の「家族向け手順書」を最新に保つ。

## 4. 投資戦略仕様(v1)

**コア・サテライト + トレンドフィルタ**(実装: `src/smz_trader/strategy.py`、パラメータ: `config/config.toml`)

- **リスクオン判定**: SPY終値 > 200日SMA。下回ったら**全額現金**(暴落時の生存性最優先)。
- **コア(70%)**: SPY/QQQ のうち 12-1ヶ月モメンタムが高い方を1本保有。
- **サテライト(30%)**: 米大型株40銘柄のホワイトリストから、12-1モメンタム上位5銘柄
  (200日SMA上抜け・モメンタム正)を逆ボラティリティ配分(1銘柄上限10%)。
- **リバランス**: 月次(月初第1営業日)。乖離が目標の20%以内なら売買しない(コスト・税の抑制)。
- **通貨**: 口座は円建て評価、米国株はUSD建て(為替リスクあり。ヘッジはしない=コスト優先)。

**なぜ米国株から始めるか**: 端数株(フラクショナル)により20万円でも分散が組めるため。
日本株は単元(100株)制約で20万円では1〜2銘柄しか買えず、分散が成立しない。

**正直な期待値**: この種の戦略の長期実績レンジはおおむね「市場並みのリターンで、
ドローダウンが浅い」(年率5〜12%程度、最大DD 15〜25%)。29.8%は出ない。
だからこそ §1-3 の Plan B が主経路。

**生存者バイアス警告**: 「現在の」大型株リストでのバックテストは過去に遡るほど成績が
過大評価される。バックテストは設定間の相対比較にのみ使い、絶対値を信じない。

## 5. リスク管理(要約 — 正典は docs/02_risk_policy.md)

1. 現物のみ / 空売り禁止 / ホワイトリスト外の売買不可(コードで強制)
2. サーキットブレーカー: 高値からDD25%で全売却+停止 / 月間損失10%で停止 / 資産5万円割れで完全停止
3. フェイルセーフ原則: データ取得失敗・API異常・台帳不整合 → **何もしない**(現金保持がデフォルト)
4. AIの権限はリスク低減方向のみ(買いのveto/縮小)。設定変更・銘柄追加・増額は構造的に不可能
5. 全イベントはハッシュ連鎖付き台帳に記録(改竄検出可能)。税務・監査の一次資料

## 6. 資金管理

- **入金**: `smz-trader deposit <金額>`。積立は任意(§1-2のレバー)。
- **出金**: `smz-trader withdraw <金額>` でいつでも。現金不足時は低モメンタム銘柄から自動売却プランを提示。
  ドローダウン中の出金は損失確定になることだけ意識(システムは止めない)。
- **成績評価は時間加重リターン(TWR指数)**: 入出金の影響を除いた運用成績で判断する(出金しても「成績」は下がらない)。
- **フロア**: 総資産5万円割れ → 全停止 → 敗因分析をAIと文書化してから、再開/撤退を決める。

## 8. レビュー運用と kill 基準

- **月次(15分)**: 月次レポート確認 / verify-ledger / ブレーカー・拒否注文の妥当性 / 積立するか決める。
- **年次(1時間)**: TWRを単純ベンチマーク(SPY買い持ち円換算)と比較 / パラメータ見直しは年1回まで / 本計画書の前提を読み直す。
- **戦略 kill 基準**: 3年ローリングでベンチマークに大幅劣後(年率-5%pt以上)が2回連続 →
  サテライト廃止・コア(インデックス)のみへ縮退。**「もっと複雑にする」は敗着**。
- **設定変更の手続き**: リスク緩和方向の変更は、変更PRを作成 → 24時間置く → 翌日冷静に自己レビューしてからマージ(docs/02)。

## 9. 想定プレイブック(起きてから慌てない)

| 事象 | 対応 |
|---|---|
| 暴落(-20%超の急落) | 何もしない。トレンドフィルタとブレーカーが機構的に対応する。手動介入は禁止(唯一の例外: `halt`で止めるのは常に可) |
| データソース死亡(Stooq等) | フェイルセーフで自動停止 → `config.toml` のproviderを代替(Alpaca/J-Quants)に切替 |
| ブローカー障害・破綻 | 米国: SIPC(50万ドルまで)/ 日本: 投資者保護基金(1000万円まで)。口座情報はdocs/04に記録 |
| Claude API停止 | 影響なし(AIレビューはスキップされ、ルールベースで完結) |
| 本人の長期不在・不測の事態 | システムは新規売買を続けるが、家族はdocs/04の手順で `halt` → 全売却 → 出金ができる |
| 税務調査 | 台帳(ledger.jsonl)+年次エクスポートが一次資料。docs/04の税務チェックリスト |
