## 設計原則

1. **依存最小化(15年運用)**: コアは標準ライブラリのみ。外部依存はAIアドバイザーの
   `anthropic` SDK(任意インストール)だけ。ライブラリの腐敗がシステムを殺さない。
2. **単一の真実 = 台帳**: 状態はDBではなく追記専用JSONL。ポートフォリオは常に
   台帳リプレイで再構築(キャッシュした状態を信じない)。ハッシュ連鎖で改竄検出。
3. **決定論**: 戦略・約定に乱数と実時間依存なし。同じ価格履歴からは常に同じ結果
   → ペーパー口座は `inception` からのリプレイで完全再構築でき、**状態消失が怖くない**。
   バックテストと本番が同じコードを通る。
4. **フェイルセーフ = 現金**: 異常時のデフォルト動作は常に「何もしない」。
5. **AIは補佐**: 判断の主体はルール。AIの権限はリスク低減方向のみ(docs/02 R5)。

## モジュール一覧

| ファイル | 責務 | 依存 |
|---|---|---|
| `config.py` | TOML設定の読込・検証 | stdlib (tomllib) |
| `data.py` | 価格取得(Stooq/CSV)+キャッシュ | stdlib (urllib) |
| `signals.py` | SMA/モメンタム/ボラ/DD(純関数) | stdlib |
| `ledger.py` | 追記専用・ハッシュ連鎖台帳 | stdlib |
| `portfolio.py` | 台帳→状態復元、評価、TWR指数 | stdlib |
| `risk.py` | ガードレール、ブレーカー | stdlib |
| `strategy.py` | 目標ウェイト→注文生成 | stdlib |
| `advisor.py` | Claudeレビュー(任意) | anthropic(任意) |
| `broker.py` | 約定(Paper/実弾スタブ) | stdlib |
| `backtest.py` | 同一コードでの期間シミュレーション | stdlib |
| `runner.py` | 日次サイクル統合 | 上記全部 |
| `report.py` | 日次Markdownレポート | stdlib |
| `cli.py` | コマンドライン | stdlib |

## データフロー(状態ファイル)

```
trading-agent/
├── config/config.toml      ← 唯一の設定(Git管理)
├── config/secrets.env      ← APIキー(Git管理外)
└── state/                  ← 実行時状態(Git管理外)
    ├── ledger.jsonl        ← 台帳(唯一の真実。月1バックアップ推奨)
    ├── cache/*.csv         ← 価格キャッシュ(消えても再取得可)
    ├── reports/daily_*.md  ← 日次レポート
    └── backtests/*.csv     ← バックテスト結果
```

## 障害時の振る舞いマトリクス

| 障害 | 検知 | 動作 | 復旧 |
|---|---|---|---|
| 価格API死 | fetch_all例外 | 売買せずNOTE記録 | プロバイダ切替 or 翌日自動回復 |
| キャッシュ消失 | — | 再取得 | 自動 |
| 台帳消失 | 起動時 | エラー停止 | バックアップ復元 or inceptionからリプレイ |
| 台帳改竄 | verify_chain | エラー停止 | バックアップと突合(自動修復しない) |
| Claude API死 | advisor例外 | ルールベースで続行 | 自動 |
| プロセス死(実行漏れ) | 翌日のrun-daily | 冪等に追いつく(月初を跨いだ場合は次の月初にリバランス) | 自動 |

## 実行環境

- **想定**: ユーザーのローカルマシン / Dev Container(cron等で日次実行)。
- Claude Code のクラウド実行環境は現状、市場データドメイン(stooq.com等)への
  egress がブロックされているため、**環境のネットワーク許可設定を変更しない限り
  データ取得はローカルでのみ動作**する(docs/04 参照)。
- Python 3.11+。インストール不要で `PYTHONPATH=src python3 -m smz_trader ...` でも動く。
