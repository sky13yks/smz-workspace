# moomoo証券で始める完全ガイド(超初心者向け)

対象: 山口 朔矢(個人資金・会社業務とは別)。証券・プログラムの知識ほぼゼロ前提で、
**実際にお金を動かすまでの一挙手一投足**を書く。最終調査 2026-07。
凡例: 【人間】=あなたが手でやる / 【システム】=smz-traderが計算する / 【確認】=あなたが目で見て確かめる。

> ⚠️ 焦らない。まず docs/00 の「ゴールの数学」を読み、Phase 1(3ヶ月ペーパー)合格を待つのが大前提。
> このガイドはその後の Phase 2(実弾)で読むもの。

---

## 0. 全体像 — 誰が何をやるか

このシステムは「**頭脳(何を売買すべきか)**」で、「**手足(実際の発注)**」はあなたか API。
役割分担はこう:

| やること | 誰 |
|---|---|
| moomoo口座の開設・入金・両替設定 | 【人間】(100%手作業。自動化しない) |
| 毎月「何をいくら買う/売る」の計算 | 【システム】`smz-trader` |
| moomooアプリで実際に注文ボタンを押す | 【人間】(最初はこれ。慣れたら将来API化) |
| 売買した内容を台帳に記録 | 【人間】1コマンド(`record-fill`、下記§5) |
| 資産評価・成績・リスク監視・停止判断 | 【システム】+【あなたの確認】 |

**最初は「システムが指示 → あなたが手で発注」の半手動で始める**のを強く推奨する。理由は §5。

## 1. なぜmoomooが本戦略に向くのか(3つの決定的な理由)

調査で確定した事実(2026-07):

1. **米国株の端数株(micro米国株)に対応** → 20万円でも複数銘柄に分散できる(単元株制約を回避)。
   本戦略は端数株が前提なので必須条件を満たす。
2. **特定口座(源泉徴収あり)で取引できる** → 口座内で税金を自動計算・源泉徴収 →
   **原則、確定申告が不要**。海外業者(Alpaca/IBKR)の「毎年確定申告+損失繰越不可」という
   隠れコストを回避できる(docs/03 §4)。**これがAlpacaより明確に優れる最大の点。**
3. **多通貨買付(円含む)+為替手数料無料** → 日本円を入れるだけで米国株を買える。
   自分でドルに両替する手間が要らない(Alpacaは自分でUSD入金が必要だった)。

> 出典: moomoo公式ヘルプ(micro米国株/口座種別/多通貨買付)、各種解説記事。§10にリンク。

## 2. Phase 2-A: 口座開設【人間】(所要 スマホで15分+審査数日)

1. スマホに **moomoo証券(日本)** アプリを入れる(または公式サイト moomoo.com/jp)。
2. 「口座開設」→ 本人確認(マイナンバーカード or 免許証+通知カード)。銀行口座も用意。
3. **口座種別で必ず「特定口座(源泉徴収あり)」を選ぶ**。← 確定申告を自動化する肝。迷ったらこれ。
4. NISAの扱い(重要な判断):
   - NISA枠(年間の非課税枠)は**手動で**、全世界株やS&P500の投信・ETFを積み立てるのに使うのが定石。
   - **本システム(自動売買する課税口座=特定口座)とは分ける**。理由: NISAは頻繁な売買やAPIと相性が悪く、
     枠を使い切ると復活しない。§docs/03 §2「NISAと自動売買」。
   - つまり: **NISA=手で積立(守り) / 特定口座=システム運用(攻め)** の二本立て。
5. 審査通過を待つ(数日)。ログインできたら口座開設完了。

**【確認】** ログインして口座種別が「特定口座(源泉徴収あり)」になっているか。違っていたら変更手続き。

## 3. Phase 2-B: 入金【人間】(所要 5分)

1. moomooにログイン → 画面下の **「口座」** → **「今すぐ入金する」**。
2. 入金方法を選ぶ(即時入金 or 銀行振込)。**まずは少額**(例: 1〜2万円)で入金操作を試す。
   - ⚠️ いきなり20万円入れない。最初は「操作を覚えるための1万円」。
3. **「多通貨買付(円含む)」をONにする**: 「口座」→「その他」→「取引設定」→
   「多通貨買付(円含む)」を**オレンジ(有効)**に。これで円のまま米国株が買える。

**【確認】** 「口座」画面の預り金に入れた金額が反映されているか。

## 4. Phase 2-C: 手で1株だけ買ってみる【人間】(操作を覚えるため)

システムに任せる前に、**自分の手で1回売買を最後まで通す**。これで画面と用語に慣れる。

1. 銘柄検索で例えば `SPY`(S&P500 ETF)を出す。
2. 「買い」→ **数量を「端株(micro)」で 0.02株など極少**に → 注文種別は **成行(Market)** を選ぶ。
   - 成行=「今の値段でいいから確実に買う」。本システムも成行を使う。
3. 「買い」ボタン → 取引パスワードを入力 → 発注。
4. 約定したら「保有」に出る。次に同じ手順で**売って**みる(全部売却して現金に戻す)。

これで「買う・売る・約定を見る」の3つが体で分かる。**ここまでが操作の練習。**

**【確認】** 買い→売りを1往復できたか。手数料・為替でいくら差し引かれたかを見ておく。

## 5. Phase 2-D: システムと組み合わせて運用する(推奨の始め方=半手動)

### なぜ「半手動」で始めるのか

- 本戦略は**月1回のリバランスだけ**。売買するのは毎月せいぜい5〜7銘柄。
  → **手でやっても月に数分**。完全自動化の複雑さ・故障リスクを負う意味が小さい。
- moomooの完全自動化(OpenAPI)は、PC常駐の「OpenD」というゲートウェイを動かし続ける必要があり、
  初心者にはハードルと運用負担が高い(§7)。まず半手動で仕組みを体で理解するのが安全。

### 毎月の流れ(月初の第1営業日、5〜10分)

```
【システム】1. smz-trader が「今月はこれを買え/売れ」を計算して一覧表示
   ↓
【人間】   2. その一覧の通りに、moomooアプリで成行注文を出す(端株で数量指定)
   ↓
【人間】   3. 約定した実際の株数・値段を smz-trader に記録する(record-fill)
   ↓
【システム】4. 台帳が更新され、資産評価・成績(TWR)・税務記録が正しく保たれる
```

> このうち **1(指示)と 3(記録)を smz-trader 側に用意する小コマンド**(`manual`モード +
> `record-fill`)は、あなたが口座を開けた後に実装する(次のステップ)。今は「そういう流れになる」
> とだけ理解しておけばよい。現状のコードでは Alpaca API 経由の完全自動しか実装されていないので、
> moomoo半手動用の薄い仕組みを足す。

### 毎日やること(任意・慣れたら)

- 米国市場クローズ後(JST朝)に `smz-trader run-daily` を実行 →
  資産評価とリスク監視(サーキットブレーカー)が回る。売買指示が出るのは月初だけ。
- これは cron で自動化できる(docs/04 §1)。**評価・監視は自動、発注だけ手動**、という切り分け。

## 6. 「任せた後」に確認すること(ハンドオフ後のチェックリスト)

システムに評価・監視を任せた後、**あなたが目で見て確かめる**のはこれだけ。

### 毎日(30秒・慣れたら見なくてよい)
- [ ] `smz-trader status` → 総資産とポジションがおかしくないか
- [ ] 何かエラー(`no_data`が続く等)が出ていないか

### 毎月(15分・第1土曜など固定)
- [ ] 月初のリバランス指示通りに発注し、`record-fill`で記録したか
- [ ] **moomooアプリの保有銘柄・株数 と 台帳が一致するか目視照合**
      (システムのAlpaca版なら`reconcile`が自動でやる。moomoo手動なら自分の目で)
- [ ] `smz-trader verify-ledger` → ✓ が出るか(台帳が壊れていないか)
- [ ] 拒否注文・サーキットブレーカー発動が妥当だったか
- [ ] 台帳ファイル(`state/ledger.jsonl`)をGoogle Driveにコピー(バックアップ)
- [ ] 今月いくら積み立てるか決める(任意。docs/00 §1-2)

### 四半期・年次
- [ ] 成績(TWR)を「ただS&P500を買って持っていた場合」と比較(docs/04 §4)
- [ ] docs/00 の大前提と数学を読み直す

### 🚨 これが出たら人間が止める / 確認する(docs/00 §9)
- サーキットブレーカーが自動発動(高値から-25% / 月-10% / 資産5万円割れ)
  → **まず何もしない(それが正常動作)**。一晩置いてから docs/02 を読み `resume` 判断。
- `verify-ledger` が ✗ → 台帳を手で触らず、バックアップと突き合わせ。
- とにかく不安 → いつでも `smz-trader halt` で止めてよい(理由不要)。
  moomoo側の実ポジションを止めたい時は moomooアプリで手動売却も併用。

## 7. 将来: 完全自動化(moomoo OpenAPI)の位置づけ

- moomoo証券は**個人が無料で使えるOpenAPI**を提供(Python SDK、米国株の自動発注可、金商法上も個人の
  自己資金自動売買は問題なし)。将来ここまで行ける。
- ただし構成はAlpacaより重い: **「OpenD」というゲートウェイ常駐アプリ**をPCで動かし続け、SDKがそこに繋ぐ方式。
  無人運用には常時起動のPC/サーバが要る。
- **やる条件**: 半手動で最低3〜6ヶ月回し、リバランスと記録の流れが完全に手に馴染んでから。
  その時 `broker.py` に `MoomooBroker` を1クラス追加する(Alpaca版と同じインターフェース)。
- 急がない。**「手で月数分」で困っていないなら、自動化しないのが一番壊れない。**

## 8. 税金(特定口座 源泉徴収ありの場合)

- 上場株式の譲渡益・配当は **申告分離課税 20.315%**。
- **特定口座(源泉徴収あり)なら口座内で自動天引き → 原則、確定申告は不要**。
- 米国株の配当は米国で源泉10% → 二重課税。取り戻すには外国税額控除(確定申告)が要るが、
  少額なら手間と見合わないことも。金額が増えてきたら税理士に相談(台帳を渡せる形で記録済み)。
- 端数株の税務も単元株と同じ扱い。ただし**端株の売却ルールに注意点があるとの記載があるため、
  口座開設後に moomooヘルプで「micro米国株の売却条件」を必ず自分で確認**すること
  (本戦略は毎月端株を売買するので、自由に売れることが前提)。【要確認】

## 9. やってはいけないこと(絶対)

- 信用取引・レバレッジ・オプション・レバレッジ型ETF(借金になる。現物のみ)
- 生活費・事業資金・会社の金の投入(余剰資金のみ。これは会社と完全に別の個人運用)
- ドローダウン中に「取り返す」ための裁量売買、設定の緩和(docs/02 R7)
- 台帳ファイル(`ledger.jsonl`)の手編集(ハッシュ連鎖が壊れて停止する。それが正しい動作)
- 「もっと頻繁に売買すれば儲かる」という発想(税・手数料で複利が壊れる。docs/00 §2)
